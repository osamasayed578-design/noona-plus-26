## مركز التقارير

- الكتالوج في `tools/bi_catalog.py` (يولد `db/seed/14_reports_catalog.sql`): لكل تقرير الوحدة والتطبيق والصفحة ورمز التقرير داخل
  مركز تقارير الوحدة والصلاحية المطلوبة. عند إضافة تقرير في أي تطبيق أضفه هناك وأعد التوليد ثم شغّل ملف البذرة.
- الظهور: الوحدة مشترك فيها (لوحة المنصة) + للمستخدم دور في الوحدة + صلاحية التقرير (مثل `GL_JOURNAL.VIEW`)؛ مسؤول المؤسسة يرى كل المشترك فيه.
- مركز التقارير نفسه يظهر في شاشة الأنظمة لكل من له تقرير واحد على الأقل.
- فتح التقرير يمر بصفحة `OPEN` في مركز التقارير (تتحقق من الصلاحية وتسجل الفتح) ثم ينتقل للتقرير في تطبيق وحدته.

## الدخول الموحد

- الدخول من التطبيق الرئيسي 115 فقط؛ كل التطبيقات الأخرى تحيل غير المسجلين وتسجيل الخروج إلى صفحة دخوله.
- الجلسة مشتركة عبر الكوكي `NOONA_SESSION`؛ شريط كل تطبيق فيه رابط **الأنظمة** للعودة.
- شاشة الأنظمة تعرض فقط الأنظمة التي **اشتركت فيها المؤسسة** (لوحة المنصة ← الوحدات المشترك فيها)
  **وللمستخدم صلاحية** في إحدى وحداتها (مسؤول المؤسسة يرى كل المشترك فيه)، وتتكيف مع عددها.
- المصادقة: كلمات مرور نونا المحلية (PBKDF2 مع قفل بعد 5 محاولات)؛ المستخدم الذي لا يملك كلمة مرور
  محلية بعد يدخل بحساب APEX حتى يغيرها من **تغيير كلمة المرور**.

## الاستيراد

1. حدث قاعدة البيانات أولاً: `db\update_windows.bat` (أو `install_windows.bat` لتثبيت جديد).
2. App Builder ← Import ← ملف الـ zip ← Parsing Schema = `NOONA_APP` ← **Reuse Application ID**
   (أو Change Application ID إن كان الرقم محجوزاً؛ الـ Alias هو المهم).
3. احذف أي نسخة قديمة بنفس الـ Alias قبل الاستيراد، وإلا يضيف APEX رقماً للـ Alias.
4. بعد الاستيراد: Ctrl+F5 في المتصفح.

## مكان حفظ ملفات الأرشيف

الافتراضي داخل قاعدة البيانات. لحفظ ملفات مؤسسة في مجلد على الخادم أو NAS ينشئ مسؤول قاعدة البيانات (SYS) مجلداً لها:

```sql
CREATE DIRECTORY NOONA_DMS_T<رقم المؤسسة> AS '/mnt/noona/<المؤسسة>';      -- أو NOONA_DMS_T<رقم>_<اسم> لأكثر من مجلد
GRANT READ, WRITE ON DIRECTORY NOONA_DMS_T<رقم المؤسسة> TO NOONA_OWNER;
```

ثم من تطبيق المستندات ← الإعدادات ← مكان حفظ الملفات: اختر المجلد، احفظ، اختبر الاتصال، وانقل الملفات السابقة إن أردت.
تظهر لكل مؤسسة مجلداتها فقط. شعار الشركة يبقى في قاعدة البيانات.
