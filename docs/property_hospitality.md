# نونا بلس: العقارات والضيافة والصيانة (التطبيق 139)

التطبيق 139 (`NOONA_PRJ`) هو تطبيق «العقارات والضيافة والمشروعات». يجمع داخله ثلاثة موديولات تعمل على سجل عقاري واحد، فلا تتكرر بيانات الوحدات:

- السجل العقاري.
- الضيافة: الفنادق والشقق الفندقية.
- الصيانة.

الإيجارات وبيع الوحدات والمشروعات والمقاولات مراحل قادمة، وستبنى على السجل العقاري نفسه.

## التحديث

1. نفّذ `git pull origin main` ثم شغّل `db\update_windows.bat`.
   - يطبق الترقية `upgrade_23_property_hospitality`.
   - اختبار `test_property_hospitality` يجب أن ينتهي بـ `72 passed, 0 failed`.
2. استورد `apex\NOONA_PRJ\f139_NOONA_PRJ.zip` مع **Reuse Application ID** (الاسم المستعار `NOONA_PRJ`).
3. ادخل «العقارات والضيافة» واضغط **تجهيز الضيافة والصيانة** (مرة واحدة لكل شركة). يضيف:
   - الحسابات:
     - `1112` ذمم النزلاء.
     - `1113` حسابات الشركات (City Ledger).
     - `4110` إيرادات الإيواء.
     - `4111` إيرادات خدمات الضيافة.
   - 11 نوع عطل بأزمنة إنجاز مستهدفة: سباكة، كهرباء، تكييف، نجارة، دهانات، أجهزة، مصاعد، نظافة، شبكات، سلامة، أعمال عامة.
   - فريق صيانة عاماً.
   - الترقيم.
4. (اختياري) `db\demo_windows.bat` يحمّل بيانات تجريبية:
   - فندق من 24 غرفة.
   - شقق فندقية من 12 شقة.
   - عمارة سكنية من 20 شقة.
   - تشغيل ثلاثة أيام سابقة مدققة، ونزلاء مقيمون.
   - وصول اليوم وحجوزات قادمة.
   - فريقا صيانة، و7 بلاغات بكل الحالات.

## السجل العقاري

- **إضافة عقار (معالج بخطوة واحدة)** يجمع في شاشة واحدة:
  - بيانات العقار: النوع، المدينة، العنوان، الفرع، المالك، التصنيف، الترخيص، الوصف.
  - حتى ثلاثة مبانٍ بعدد طوابقها، والدور الأرضي اختيارياً.
  - توليد الوحدات بعدد ثابت في كل طابق وترقيم آلي: رقم الطابق ثم تسلسل الوحدة (101، 102 ... 201).
  - تفاصيل الوحدات: النوع، الاستخدام، الغرف، الحمامات، المساحة، التأثيث، السعر.
  - «تشغيل الوحدات فندقياً»: يجعل كل وحدة غرفة أو شقة فندقية جاهزة في الاستقبال، بنوع غرفة وسعر ليلة.
- **بطاقة العقار:**
  - المؤشرات ونسبة الإشغال.
  - **مخطط الوحدات** لكل مبنى وطابق، ملوناً بالحالة: متاحة، محجوزة، مؤجرة، مباعة، تحت الصيانة.
  - تعديل البيانات، وإضافة مبنى جديد وتوليد وحداته.
- **الوحدة:**
  - التفاصيل والتجهيزات ورقم الصك والسعر، وتغيير الحالة.
  - بلاغات الصيانة عليها، وزر «بلاغ صيانة لهذه الوحدة».

## الضيافة

| الشاشة | المحتوى |
|---|---|
| لوحة الاستقبال | المؤشرات: تاريخ العمل، الإشغال، وصول ومغادرة اليوم، الشاغرة المتاحة، تحت التنظيف، خارج الخدمة، إيراد الشهر. **حالة الغرف**: بطاقة لكل غرفة حسب الطابق، ملونة بالحالة، مع فلاتر بالعدد والبحث برقم الغرفة أو اسم النزيل. **مخطط الحجوزات**: الغرف مقابل الأيام لأسبوعين؛ النقر على خانة فارغة يفتح حجزاً لتلك الغرفة |
| النقر على غرفة | **شاغرة**: دخول سريع (الاسم، الجوال، الهوية، الليالي، السعر المقترح من الخطة، دفعة مقدمة، الإجمالي مع الضريبة)، أو حجز مستقبلي، أو بلاغ صيانة، أو تغيير حالة النظافة. **وصول اليوم**: تسجيل الدخول أو عدم الحضور. **مشغولة**: بيانات النزيل، حساب النزيل بحركاته ورصيده والليالي غير المرحلة والمستحق، ثم دفعة أو استرداد، خدمة (مغسلة، ميني بار، مطعم، خصم)، تمديد أو تقصير، نقل لغرفة متاحة، مغادرة مع تحويل الرصيد لحساب شركة، وطباعة الفاتورة. **خارج الخدمة**: إعادة للخدمة |
| الحجوزات | الوصول المتوقع اليوم وكل الحجوزات بالقناة والعربون والحالة |
| حجز جديد | النزيل (يتعرف عليه بالهوية أو الجوال إن سبق تسجيله)، الشركة الحاجزة، التواريخ، نوع الغرفة مع عدد المتاح، غرفة محددة اختيارياً، خطة السعر، القناة ومرجعها، الطلبات الخاصة، العربون وطريقة سداده |
| الحجز | التفاصيل والرصيد، تسجيل الدخول (مع تغيير الغرفة أو الدخول قبل اكتمال التنظيف)، الإلغاء، عدم الحضور، كشف الحساب |
| كشف حساب النزيل | فاتورة إقامة للطباعة: الرسوم والضريبة والمدفوع والرصيد |
| التدبير الفندقي | حالة نظافة كل غرفة بنقرة (تحتاج تنظيف، جاري التنظيف، نظيفة، مفحوصة)، ومهام التنظيف المفتوحة وإسنادها للعاملين |
| التدقيق الليلي | يسجل عدم الحضور، ويرحل ليلة كل نزيل مقيم، ويحسب الإشغال ومتوسط السعر، ويجعل الغرف المشغولة بحاجة لتنظيف يومي، ثم ينقل تاريخ العمل لليوم التالي |
| إعداد الضيافة | أنواع الغرف وسعتها وسعرها الأساسي. خطط الأسعار: يومي للفنادق، أسبوعي وشهري للشقق، الوجبات، شامل الضريبة أو لا، سياسة الإلغاء. الأسعار الموسمية بالفترات. إضافة غرف أو إنشاؤها من وحدات العقار |
| تقارير الضيافة | النزلاء المقيمون وأرصدتهم، الإشغال اليومي (ADR وRevPAR)، الوصول والمغادرة القادمة، حسابات الشركات المحولة |

### قواعد الضيافة

- **منع الحجز المزدوج:** صف لكل غرفة وليلة بقيد فريد. لا تحجز غرفة ليلتين متداخلتين، ولا يمدد نزيل على ليلة محجوزة لغيره.
- **تاريخ العمل الفندقي:**
  - الليلة تحسب بتاريخ العمل لا بساعة الجهاز. الدخول بعد منتصف الليل وقبل التدقيق يحسب على ليلة اليوم السابق.
  - تاريخ العمل يتقدم بالتدقيق الليلي.
- **احتساب الليالي:**
  - ترحل الليلة لكل مقيم بالتدقيق الليلي.
  - عند المغادرة ترحل الليالي المتبقية.
  - الدخول والخروج في يوم العمل نفسه يحسب ليلة واحدة.
- **الضريبة:**
  - تضاف ضريبة القيمة المضافة 15% على الغرف والخدمات.
  - الخطة «شامل الضريبة» تقسم السعر إلى صافٍ وضريبة.
- **المغادرة:**
  - تتطلب رصيداً صفراً، أو تحويل الرصيد المستحق لحساب شركة (City Ledger).
  - بعدها تصبح الغرفة «تحتاج تنظيف» وتنشأ مهمة تنظيف.
- **الدخول:** يرفض الدخول لغرفة غير نظيفة إلا باختيار صريح، ويرفض لغرفة مشغولة أو خارج الخدمة.

## الصيانة

- **طرق البلاغ (القناة):**
  - الاستقبال: من بطاقة الغرفة في لوحة الاستقبال.
  - الهاتف، والبريد، وبوابة الخدمة، وتطبيق الجوال.
  - جولة المعاينة، والصيانة الوقائية.
  - يسجل اسم المبلغ وجواله إن لم يكن مستخدماً.
- **البلاغ:**
  - يحدد نوع العطل والأولوية والموقع: العقار ثم الوحدة أو الغرفة.
  - يحدد من يتحمل التكلفة: المالك، المستأجر أو النزيل، الضمان، المقاول، التأمين.
  - «إيقاف الغرفة الشاغرة حتى الإصلاح» يخرجها من البيع والاستقبال.
- **زمن الإنجاز المستهدف:**
  - من نوع العطل، والأولوية الأعلى تقصره: طارئ ساعتان، عاجل 4 ساعات، مرتفع يوم، عادي 3 أيام، منخفض أسبوع.
  - يظهر لكل بلاغ: في الوقت، قارب الموعد، متأخر، أنجز في الموعد أو متأخراً.
- **دورة البلاغ:**
  1. جديد.
  2. **إسناد** لفريق وفني: ينشئ أمر عمل، ويشعر مشرف الفريق والفني في «مهامي وإشعاراتي».
  3. بدء التنفيذ، أو تعليق بسبب (انتظار قطع غيار).
  4. **إنجاز**: ما تم عمله، وساعات الفني (بتكلفة الساعة)، وتكلفة المواد. تعود الغرفة الموقوفة للخدمة وتنشأ مهمة تنظيف عميق.
  5. **إغلاق** بتقييم المبلغ من 1 إلى 5، أو إعادة فتح.
  - يمكن الإلغاء أو الرفض بسبب.
- **الشاشات:**
  - لوحة البلاغات حسب الحالة، مرتبة بالأولوية والموعد، بفلتر العقار والفريق.
  - سجل البلاغات.
  - الفرق والفنيون (موظفون أو فنيو مقاول) وأحمالهم وساعاتهم.
  - أنواع الأعطال.
  - أداء الصيانة لكل نوع: العدد، والمنجز، ونسبة الالتزام بالموعد، ومتوسط زمن الإنجاز، والتكلفة، والرضا.
