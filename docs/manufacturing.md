# نونا بلس: وحدة التصنيع (التطبيق 135)

## التحديث

1. نفذ `git pull origin main` ثم شغل `db\update_windows.bat`.
   - يطبق الترقية `upgrade_17_manufacturing` (أعمدة جداول التصنيع، حركة إرجاع الخامات، أحداث التصنيع المحاسبية، الحزمة `NOONA_MFG_PKG`).
   - يشغل الاختبارات؛ اختبار التصنيع `test_manufacturing` يجب أن ينتهي بـ `77 passed, 0 failed`.
2. استورد `apex\NOONA_MFG\f135_NOONA_MFG.zip` مع **Reuse Application ID** (الاسم المستعار `NOONA_MFG`).
3. ادخل من التطبيق الرئيسي ← «التصنيع» ← زر «تجهيز التصنيع» (مرة واحدة). يضيف:
   - الحسابات: `1110` الإنتاج تحت التشغيل (حساب مراقبة)، `5103` العمالة الصناعية المحملة، `5104` الأعباء الصناعية المحملة، `5105` انحرافات تكاليف الإنتاج.
   - ترقيم أوامر الإنتاج `MO-` وطلبات الشراء `PR-`، ومركز عمل افتراضي.
4. (اختياري) `db\demo_windows.bat` يحمل بيانات التجارة ثم بيانات التصنيع التجريبية؛ إعادة تشغيله لا تكرر شيئاً.

| أحمال مراكز العمل | الحمل اليومي لكل مركز مقابل طاقته؛ الأحمر تجاوز الطاقة |

## دورة أمر الإنتاج

```
مخطط ← معتمد ← مطلق للتنفيذ ← قيد التنفيذ ← منجز جزئياً ← مكتمل ← مقفل
                     ↘ موقوف (بسبب) ↗              ↘ ملغى (قبل أي تكلفة)
```

- **الحفظ**: تحسب الاحتياجات من قائمة المواد المنشورة (القوائم الوهمية تفك إلى مكوناتها، والهالك يضاف)، والعمليات من المسار، والتكلفة المعيارية للوحدة لكل عنصر.
- **الإطلاق**: يثبت إصدار القائمة والمسار والتكلفة المعيارية بأسعار وقت الإطلاق؛ لا يعدل الأمر بعدها. القائمة أو المسار المستخدم في أمر مطلق لا يعدل: «إصدار جديد».
- **صرف الخامات**: حركة مخزون لكل مستودع بالمتوسط المرجح (الدفعات بالأقدم انتهاءً ولا تصرف دفعة منتهية)، ويمكن صرف مادة إضافية خارج القائمة.
- **تقرير العملية**: لا تتجاوز الكمية المقبولة ما أنجزته العملية السابقة؛ الزمن × معدلات مركز العمل يحمل على الأمر.
- **الاستلام**: لا يتجاوز المقبول في آخر عملية. إذا كان في المسار نقطة جودة (أو اخترت «إلزامي») يبقى الإنتاج «بانتظار الجودة» خارج المخزون حتى الفحص. إعادة الإرسال بنفس المفتاح لا تكرر الاستلام.
- **فحص الجودة**: المقبول يدخل المخزون بالتكلفة المعيارية (بدفعة الأمر)، والمرفوض يحمل على حساب العجز والتلف `5213`. المنتج المشترك يستلم بنسبة المقبول.
- **الإقفال**: يكمل الأمر ثم يرحل رصيد الإنتاج تحت التشغيل كانحرافات ويحلله (سعر الخامات، كمية الخامات، كفاءة العمالة، التحميل)؛ يصبح رصيد الأمر صفراً.

تقرير «الرقابة المالية» في المالية يطابق رصيد الحساب `1110` مع أرصدة أوامر الإنتاج.

## تخطيط احتياجات المواد (MRP)

- **الطلب**: أوامر البيع المفتوحة + المتبقي غير المصروف لأوامر الإنتاج المفتوحة + الوصول للحد الأعلى للأصناف تحت الحد الأدنى.
- **الوارد**: الرصيد + المتبقي من أوامر الإنتاج المفتوحة + أوامر الشراء المعتمدة + طلبات الشراء القائمة.
- يحسب المستوى الأدنى لكل صنف ثم صافي الاحتياج مستوى بمستوى؛ الصنف الذي له قائمة منشورة «تصنيع» وينفجر على مكوناته، وغيره «شراء».
