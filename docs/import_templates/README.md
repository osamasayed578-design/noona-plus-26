# نماذج استيراد البيانات (Excel)

نماذج جاهزة لشاشة «إدارة المؤسسة ← بدء التشغيل ونقل البيانات». احذف صفوف المثال، وعبئ بياناتك تحت العناوين نفسها، ثم ارفع الملف.

الترتيب: 01 إلى 05 البيانات الأساسية، ثم 06 إلى 09 الأرصدة الافتتاحية في تاريخ بدء العمل على النظام.

- **06 أرصدة الحسابات:** من ميزان المراجعة. حسابات العملاء والموردين والمخزون والأصول تظهر للمطابقة فقط، وترحل من ملفاتها 07 و08 و09.
- **07 و08:** المبلغ السالب يعني رصيداً دائناً للعميل أو مديناً للمورد.
- **ملف الأرصدة يرحل كاملاً أو لا يرحل منه شيء.**
