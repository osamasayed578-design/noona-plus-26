# نونا بلس: أسعار الصرف لكل شركة

## المبدأ

- **أسعار الصرف خاصة بكل شركة** ومستقلة عن الشركات الأخرى في المؤسسة نفسها. لا تظهر أسعار شركة في شركة أخرى، ولا تستخدم في قيودها.
- **تدار من تطبيق المالية (127)**: الأستاذ العام ← أسعار الصرف، بعد اختيار الشركة. تتضمن:
  - إضافة سعر بنوعه (المحاسبي افتراضياً).
  - أسعار الربط الافتراضية للريال.
  - اعتماد الأسعار المعلقة أو رفضها. لا يعتمد المدخل سعره، ولا يعتمد سعر شركة أخرى.
- **إدارة المؤسسة (123)** تحتفظ بالمراجع المشتركة فقط: العملات، و**أنواع أسعار الصرف** (المحاسبي، البنك المركزي، شراء، بيع...، وهل يتطلب النوع اعتماداً). صفحة الأسعار أزيلت منها.
- القيود والسندات وكل الوحدات تقرأ السعر من أسعار الشركة الحالية فقط. السعر يحفظ في المعاملة نفسها، فتعديل الأسعار لاحقاً لا يغير المعاملات السابقة.

## التحديث

1. نفذ `git pull origin main` ثم `db\update_windows.bat`.
   - يطبق `upgrade_19_company_rates`: يضيف الشركة إلى جدول الأسعار وينسخ الأسعار القائمة (كانت مشتركة) لكل شركة في المؤسسة، ثم تعدل كل شركة أسعارها بنفسها.
   - اختبار `test_admin_ref` يجب أن ينتهي بـ `19 passed, 0 failed`.
2. استورد `apex\NOONA_ADMIN\f123_NOONA_ADMIN.zip` و`apex\NOONA_FIN\f127_NOONA_FIN.zip` مع **Reuse Application ID**.

## الصلاحيات

| الإجراء | الصلاحية (بنطاق الشركة) |
|---|---|
| إضافة سعر | `REF_EXCHANGE_RATE.CREATE` |
| اعتماد / رفض | `REF_EXCHANGE_RATE.APPROVE / REJECT` |
| نوع سعر جديد (إدارة المؤسسة) | `REF_RATE_TYPE.CREATE` |
