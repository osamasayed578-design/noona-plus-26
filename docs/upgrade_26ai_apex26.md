# تجربة الترقية: Oracle AI Database 26ai + APEX 26.2

تاريخ التجربة: 2026-10-28. البيئة: Docker على Linux، قاعدة **Oracle AI Database 26ai Free (23.26.3)**، **APEX 26.2** (أحدث إصدار متاح،
صدر 2026-10-07 ويشمل كل ما في 26.1)، **ORDS 26.3**. البيئة الحالية (21c + APEX 24.2) بقيت تعمل بجانبها للمقارنة.

## النتيجة باختصار

النظام يعمل على 26ai وAPEX 26.2 **دون تعديل في منطق الأعمال**. التثبيت من الصفر نجح، وكل الاختبارات والبيانات التجريبية
والشاشات تعمل. ما ظهر من مشاكل كان ثلاثة أخطاء تثبيت جديد (موجودة على 21c أيضاً) وتعديل واحد خاص بـ APEX 26، وكلها أصلحت.

| البند | النتيجة على 26ai + APEX 26.2 |
|---|---|
| تثبيت القاعدة كاملة (`install.sql`) | نجح، لا كائنات غير صالحة |
| اختبارات الوحدات (32 حزمة، 1,548 اختباراً) | كلها نجحت بعد الإصلاحات أدناه |
| البيانات التجريبية (14 ملفاً) | كلها حملت على قاعدة جديدة |
| استيراد التطبيقات (13 تطبيقاً بصيغة 24.2) | كلها استوردت دون أخطاء |
| فتح كل الصفحات (258 صفحة) | نفس النتيجة تماماً على 21c و26ai؛ لا أخطاء JavaScript |
| سيناريوهات الشاشات (الإيجارات، نقاط البيع، التمريض، التكاملات، المطابقة البنكية، الصناديق) | نجحت |
| واجهة REST عبر ORDS (رمز الدخول، فاتورة بمنع التكرار، الصلاحيات، OpenAPI) | نجحت |
| حزمة الذكاء الاصطناعي في APEX (`APEX_AI`) | موجودة |
| البحث الدلالي (`VECTOR` و`DBMS_VECTOR`) | يعمل |
| Select AI (`DBMS_CLOUD_AI`) | غير موجود في النسخة المحلية؛ متاح في Autonomous Database على OCI |

## ما ظهر وأصلح

1. **دور «مسؤول الشركة» لا ينشأ في التثبيت الجديد**: كان ينشأ في الترقية 18 فقط. أصبح ينشأ في بذرة المؤسسة التجريبية
   (`seed/90_demo_tenant_DEV_ONLY.sql`). يخص كل تثبيت جديد، لا 26ai وحدها.
2. **اختباران يفترضان قاعدة مستخدمة**: `test_cash` يجهز المشتريات أولاً، و`test_purchases` يمنح الحساب البنكي حد سحب على
   المكشوف داخل الاختبار (الحساب الجديد بلا رصيد بعد قاعدة منع الصرف فوق الرصيد).
3. **APEX 26 يتطلب عنصراً حول كل منطقة ديناميكية**: منطقة شارة الشركة في رأس الصفحة كانت بلا قالب في تطبيقي الدخول (115)
   والبوابة (119) فظهر خطأ JavaScript. أعيد بناؤهما بقالب «Blank with Attributes» (كانت بقية التطبيقات مبنية به أصلاً).

## ما لا يتغير وما يتغير

- **لا يتغير**: حزم PL/SQL، عزل البيانات (VPD)، التشفير، المهام المجدولة، ORDS ووحدة REST، ملفات CSS وJavaScript.
- **التطبيقات**: تبقى مولدة بصيغة تصدير 24.2 لأنها تستورد في 24.2 و26.x معاً. ننقل المولد لقالب 26.x عند اعتماد الإنتاج
  (تصدير 26.x لا يستورد في 24.2).
- **نصوص التثبيت**: تعمل كما هي على 26ai المحلية. على Autonomous Database تحتاج نسخة معدلة (أدناه).

## بيئة الإنتاج على Oracle Cloud (OCI)

| الخيار | ما هو | يناسبنا لأن | ما يلزم تعديله |
|---|---|---|---|
| **Autonomous Database (Transaction Processing)** — موصى به | قاعدة مدارة بالكامل: التحديثات والنسخ الاحتياطي والتوسع آلياً، وAPEX وORDS مدمجان ومحدثان دائماً | لا خادم ندير، Select AI متاح، نسخة مجانية دائمة (Always Free) تصلح للتجربة والعرض | التثبيت بحساب ADMIN بدل SYS، مساحة الجداول DATA بدل USERS، تخزين الأرشيف «مجلد على الخادم» يستبدل بـ Object Storage (التخزين داخل القاعدة يعمل كما هو)، صلاحية الاتصال الخارجي عبر ACL |
| **Base Database Service** | قاعدة 26ai على آلة افتراضية بإدارتنا، والترخيص ضمن الاشتراك | أقرب للبيئة الحالية، تحكم كامل | نثبت APEX وORDS وندير التحديثات بأنفسنا |
| **APEX Application Development Service** | نسخة مخفضة من Autonomous مخصصة لـ APEX | أرخص | لا اتصال مباشر بـ SQL*Plus، فلا تعمل نصوص التثبيت والتحديث الحالية كما هي |

**التوصية**: Autonomous Database (Transaction Processing) في منطقة السعودية (جدة أو الرياض حسب المتاح وقت الإنشاء، لمتطلبات
إقامة البيانات). نبدأ بنسخة Always Free للتجربة دون تكلفة، ثم نسخة مدفوعة للإنتاج بحجم يحدد من الاستخدام. الأسعار تؤخذ من
حاسبة OCI عند القرار.

## نقل البيانات من البيئة الحالية (Windows + 21c)

1. تصدير بـ Data Pump من 21c (`expdp` لمخططي NOONA_OWNER وNOONA_APP).
2. على OCI: رفع ملف التصدير إلى Object Storage، ثم الاستيراد (`impdp`) في Autonomous Database.
3. تثبيت التطبيقات واستيرادها في مساحة عمل APEX، وتشغيل وحدة ORDS، ثم تشغيل الاختبارات كاملة للتأكد.

## الخطوات التالية المقترحة

1. نسخة تثبيت لـ Autonomous Database (حساب ADMIN، مساحة DATA، منح الصلاحيات المتاحة هناك) وتجربتها على Always Free.
2. تخزين الأرشيف في OCI Object Storage كخيار ثالث بجانب «داخل القاعدة» و«مجلد الخادم».
3. بناء مزايا الذكاء الاصطناعي على APEX 26.x مع Claude (مزود مدمج في APEX)، والبحث الدلالي في الأرشيف بـ VECTOR.
