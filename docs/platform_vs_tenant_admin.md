|---|---|---|
| المستخدم | مسؤول المنصة (مزود الخدمة) | مسؤول المؤسسة، ومسؤولو الشركات الذين يعينهم |
| يرى | المؤسسات المشتركة، باقاتها وفتراتها، الحدود والاستهلاك (أعداد فقط)، الوحدات، سجل التدقيق | بيانات مؤسسته فقط |

## إدارة المنصة (التطبيق 125)

- **لوحة المنصة:** مؤشرات المؤسسات، والمشتركون الجدد خلال 30 يوماً، والاشتراكات التي تنتهي خلال 30 يوماً، والمنتهية، والتجديدات هذا الشهر، والمؤسسات بلا اشتراك مسجل. وفيها قوائم «تنتهي خلال 60 يوماً» و«منتهية (سماح / قراءة فقط / معلقة)» و«مشتركون جدد».
- **الاشتراكات:** كل المؤسسات مع الباقة ونهاية الاشتراك والأيام المتبقية وعدد المستخدمين والفروع والشركات مقابل الحدود.
- **المؤسسة:** تسجيل الاشتراك أو تعديله (الباقة، البداية، عدد الفترات أو نهاية محددة، ملاحظة برقم العقد)، والتجديد بعدد فترات (يكمل من نهاية الفترة، أو يبدأ من اليوم إن كان الاشتراك منتهياً)، وسجل التفعيل والتجديد.
- **تجهيز مؤسسة:** تختار الباقة وبداية الاشتراك مع الحدود ومسؤول المؤسسة الأول.
- **الباقات:** تجربة 14 يوماً، وشهري، وربع سنوي، ونصف سنوي، وسنوي.

### قواعد الانتهاء

تطبق يومياً الساعة 01:15 عبر المهمة `NOONA_SUBSCRIPTION_EXPIRY`، أو فوراً بزر «تطبيق قواعد الانتهاء» في لوحة المنصة:

| بعد نهاية الفترة | الاشتراك المدفوع | التجربة |
|---|---|---|
| حتى 15 يوماً | فترة سماح (العمل طبيعي مع تنبيه) | قراءة فقط |
| حتى 45 يوماً | قراءة فقط (لا معاملات جديدة) | قراءة فقط حتى 30 يوماً |
| بعدها | تعليق | تعليق |

- القواعد تصعّد حالة المؤسسة فقط، ولا تلغي إيقافاً وضعه مسؤول المنصة لسبب آخر.
- التجديد أو تسجيل فترة سارية يعيد تفعيل المؤسسة.
- كل تغيير يسجل في سجل حالات المؤسسة وسجل التدقيق.

## إدارة المؤسسة (التطبيق 123)

**مسؤول المؤسسة**
- يدير كل الشركات والفروع والمستخدمين والأدوار ومسارات الاعتماد والبيانات المرجعية.
- يعيّن **مسؤول شركة** بمنح دور «مسؤول الشركة» (`COMPANY_ADMIN`) لمستخدم، بنطاق شركة محددة.

**مسؤول الشركة يرى ويدير شركاته فقط:**
- **المستخدمون:** إنشاء مستخدمي شركته، وتعديلهم، وإيقافهم، وتعيين كلمات مرورهم.
- **الصلاحيات:** منحهم الأدوار غير المميزة بنطاق شركته أو بنطاق فرع محدد منها. لا يمنح نطاق «كل المؤسسة» ولا الأدوار المميزة.
- **الفروع:** إضافة فروع لشركته وتعديلها وإغلاقها.
- **اشتراك المؤسسة:** للاطلاع فقط (الباقة، الفترة، الأيام المتبقية، الاستهلاك مقابل الحدود).

**لا يستطيع مسؤول الشركة:**
- رؤية الشركات الأخرى أو مستخدميها، أو مسؤول المؤسسة.
- إنشاء شركات، أو تعريف الأدوار وصلاحياتها، أو تعديل مسارات الاعتماد والبيانات المرجعية.

**الحدود:** إضافة المستخدمين والفروع والشركات تتوقف عند حدود الاشتراك. رسالة المنع توضح الحد وتطلب التواصل مع مزود الخدمة لزيادته، دون أن تتأثر البيانات الحالية.

## التحديث

1. نفذ `git pull origin main` ثم `db\update_windows.bat`.
   - يطبق `upgrade_18_tenant_admin`: الباقات، ودور مسؤول الشركة لكل مؤسسة قائمة، والمهمة اليومية.
   - اختبار `test_tenant_admin` يجب أن ينتهي بـ `41 passed, 0 failed`.
2. استورد `apex\NOONA_ADMIN\f123_NOONA_ADMIN.zip` و`apex\NOONA_PLATFORM\f125_NOONA_PLATFORM.zip` مع **Reuse Application ID**.
3. المؤسسات القائمة تظهر في لوحة المنصة تحت «بلا اشتراك مسجل». سجل لكل منها اشتراكها من صفحة المؤسسة ← «الاشتراك والتجديد».

إذا ظهر عند الترقية تنبيه `WARN daily expiry job not created`، نفذ من حساب SYS:

```sql
GRANT CREATE JOB TO NOONA_OWNER;
```

ثم أعد تشغيل التحديث، أو استخدم زر «تطبيق قواعد الانتهاء» في لوحة المنصة.
